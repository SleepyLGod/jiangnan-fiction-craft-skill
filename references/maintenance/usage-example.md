# 完整使用示例：给一次搬书告别做局部修改

这是AI 编写的原创编辑演示。原稿和修改稿均为本例构造，不是用户真实稿件、模型盲测答卷或效果实验。它展示如何从问题找到材料、作出取舍；不证明使用本库优于不用，也不用于认证作者文风。

本例依据库内已有细读，没有重新核对小说全文；来源定位沿用细读记录。示例正文为原创，不改写原著场景，也不新增小说引文。

## 1. 给代理的请求与原稿

安装后，可把下面请求和原稿一起交给 Codex：

> 使用 $jiangnan-fiction-craft 修改下面的告别场景。保留三个人、搬书、明早离城和豆浆旧事，保持贴近许禾的第三人称。先指出一至两个主要问题，选少量相关材料说明理由，再给局部修改稿。不增加反转、恋爱关系或新身世；不要求模仿江南。

原稿：

> 书店快关门了，许禾来帮老周搬最后几箱书，明早他就要离城。陈叔在旁边等着拿自己订的书，三个人都有点舍不得。以前冬天收摊，许禾和老周常在店外喝豆浆，老周总问他要甜的还是咸的。许禾不知道怎么告别。老周问：“甜的还是咸的？”许禾很感动，说：“甜的。”陈叔说：“路上小心。”许禾答：“好。”

## 2. 先确定改什么，再查材料

原稿已经交代清楚人物、事情与旧事。若作者只想快速交代离开，它未必需要扩写。本例选择展开一次告别：

- “三个人都有点舍不得”替老周和陈叔作了心理判断，与限定在许禾附近的视角不合；三人的当下行为也较少。
- 豆浆旧事在问话前已经解释。本例尝试把它放到回应之后，让读者先看见两人接上话，再知道来由。这是可选的信息顺序，不是原顺序有事实错误。

从 [SKILL 的专题入口](../../SKILL.md#按需读取)进入人物与句段页，只选下面两条。不需要为了这个场景通读所有章节。

| 条目及书源 | 原有分析支持什么 | 本例为什么选择；哪些不能照搬 |
|---|---|---|
| [人物 C1](../techniques/close-reading-character.md#c1-同一清晨四种回应此间的宿舍)，`cijian:ch9:P0002–P0011`、`cijian:ch9:P0018–P0026` | 同一生活处境中，人物因想办的事、顾虑和回应办法不同而显出差别 | 这里三人同处书店；改稿让许禾搬箱、陈叔取订书、老周安排明早的豆浆，各自说话办事。没有借用原作人物性格、脏话或交换条件，也不要求每句台词都能单独辨人 |
| [句段 S3](../techniques/close-reading-sentence-flow.md#s3)，`tz2:part0688:P0015–P0020` | 一句日常问话先得到回应，随后才交代共同往事；原片段也另有先解释的安排 | 两人已有豆浆旧事，许禾知道，有限视角允许从他的回忆说明。只借回应与解释的先后；不移植原片段旁观者的内心，也不把后置说明定为更优 |

若目标是让读者从一开始就明白问话的分量，可以保留原稿的先解释。本例选后解释，是为了演示另一种可行次序；没有验证读者一定更感动。

## 3. 局部修改稿

> 许禾把最后一箱书叠到墙边。陈叔蹲着看箱侧的字，指住最下面那箱：“我那套在这儿。先别压，拿出来我就走。”
>
> 许禾重新抱起上面一箱。老周扶了一下箱角，问：“甜的还是咸的？”
>
> 许禾的手还扣在纸箱两侧。“甜的。”隔了一会儿，他又说，“少放点糖。”
>
> 冬天收摊，他们常在店外喝豆浆。老周每回都问一遍，许禾每回都选甜的。纸杯烫手，他就用两只袖口托着，等老周锁门。明早坐车以前，还有时间喝一杯。
>
> “那我早点去买。”老周说。
>
> 许禾把手里的箱子放到一旁。陈叔抱出下面那箱里的订书，把空出的纸箱往许禾脚边推了推：“明早还用你搬？”
>
> “不用了，今天搬完。”
>
> “那路上小心。”
>
> 许禾点点头，弯腰把空箱折起来。

## 4. 实际采用了什么，代价是什么

| 具体改动 | 与材料的关系 | 能确认的变化与局限 |
|---|---|---|
| 陈叔先取订书、问是否还要搬；老周安排明早的豆浆；许禾搬箱、回答、收尾 | 对应 C1 的不同任务和回应策略 | 三人不再只轮流说告别话。各人的完整形象仍未建立；取书的事务也占用了篇幅 |
| 问豆浆 → 回答 → 共同冬日经历 → 明早买豆浆 | 对应 S3 的回应先发生、旧事后说明 | 信息次序确实改变。没有证据保证后置比先置更动人；原稿直接交代的效率也损失了 |
| 不再直接说明另外两人舍不得 | 遵守本例限定视角，接入口已有视角提醒 | 保留了他们可见的言行，没有替他们确认心意。许禾的感受仍较含蓄，可能不符合想要直抒情绪的作者 |
| 纸箱位置、袖口托杯、少糖和最后折箱 | 本例的原创编辑安排，不算书源方法 | 补了可见动作与生活细节；不能因此声称这些细节由原著教会，或结尾停在折箱一定最好 |

原稿与改稿均保留三人、搬书、明早离城与豆浆旧事；没有增加反转、恋爱或身世。改稿展开了原稿未写出的动作与台词，它不是只移动句子的纯顺序实验。若不允许添加细节，应先说明这个限制，再只调整现有文字。

## 5. 交付前回看与未解决部分

纸箱先叠上去、再重新抱起放到旁边，是为了让陈叔取出底下的订书；拿走书后腾出空箱，结尾再折箱。明早买豆浆只是约定，正文没有写已经兑现。旧事由许禾知道，未进入另外两人的内心；正文中也没有混入分析清单。

本例没有篇幅硬指标。它没有检验后续章节中的告别后果、整部小说的人物弧线，也没有证明措辞更像江南。可核对的是选读材料、实际安排与理由之间的对应；是否值得这样扩写，仍由作者的节奏、情感表达偏好和上下文决定。
