# 跨章节情节线：《龙族Ⅱ》的楚子航与夏弥

本例从芝加哥相识追到本卷尾声的遗屋，讨论一条卷内有结局的关系与行动线。按正文阅读顺序核对，不按人物事后讲述重排成一份初读者早已知道的年表；也不把这一卷的结果当作全系列人物弧线已经研究完成。

检索本地《Ⅱ》83个正文分片，回读相关场面、物件交付与结尾后证。源文件与reader对应已核对；这次不是重新全文阅读全卷。以下分别标出直接动作、人物说法与编辑归纳，不推测作者起稿时已经规划了什么。原有章节、[情节P2](close-reading-plot.md)、[人物分析](close-reading-character.md)保留。

## 三项连接怎样跨章节成立

<a id="invitation"></a>

### 1. 邀约不是提过就算：从答应、准备，接到未完成的会面

邀请先有推辞与接受（`lz2:part0121:P0072–P0085`）。随后不是立刻跳到危机：楚试衣、考虑另买一身（`lz2:part0124:P0004–P0005`），看着写有“31号楼15单元201”的卡片，承认自己懂她的意思却不敢许诺（`lz2:part0125:P0025–P0026`）。提醒短信到来时，他甚至已经买好衣服并决定返回（`lz2:part0128:P0039–P0042`）。这些是可见的准备和取舍，不只是一句他很在意她。

地铁中的楚还说想赶在中午前结束、陪她回家解释（`lz2:part0132:P0034–P0035`）。战败后他问的第一批问题里就有为什么约自己去家里；夏说，若依原计划来，他不会在此时死去，却也见不到已经不再是原来夏弥的她（`lz2:part0136:P0032–P0033`）。这是她事后的计划说明，不能据此抹去正文实际写出的楚先返、再遇异象的过程，也不能保证她已经算中每一步。

钥匙在临别时才交出（`lz2:part0137:P0022–P0023`），尾声门牌与卡片地址一致，钥匙确实开门（`lz2:part0143:P0040–P0049`）。**地点与赴约事项早已出现；钥匙本身则是后段交付、后段使用，不能冒称早在相识时就埋下的物件伏笔。** 后续到访有效之处，在于继续处理前面未完成的事，同时改变到场的人、所知和目的。

<a id="knife"></a>

### 2. 折刀不只是出现过：交付、收回、再借与使用条件

| 位置 | 可以核对的状态 |
|---|---|
| `lz2:part0100:P0011–P0015` | 楚用昂热的刀切开机盖，服务眼前救援 |
| `lz2:part0103:P0036` | 昂热擦去刀上梨汁，收回自己袖内皮鞘；不能把救援时用刀直接当作楚从此一直持有 |
| `lz2:part0116:P0032–P0034` | 赴北京前，昂热明确把刀借给楚，并说明它有杀伤初代种的能力，用完要还 |
| `lz2:part0125:P0020` | 楚从手腕皮套抽刀检查自己的血，确认随身位置与持续持有；这一次使用也显出身体风险 |
| `lz2:part0136:P0023–P0024`、`lz2:part0137:P0011–P0017` | 村雨已毁，力量已耗；双方拥抱时进入近身距离，折刀成为实际出手机会 |

这里比原有P2多追到了一次明确交付和更早的使用、收回。杀伤初代种的能力在part0116已说出，不能把它全部算成结局临时增加的规则；结局仍会再解释刀的来历与作用，但不等于此前没有准备。

**旧物、随身条件和靠近的机会共同起效。** 反过来，单说楚早有一把刀仍不够：村雨已经毁坏，力量也已耗尽，双方的问答和拥抱改变了交战距离。不能把夏所有亲近动作都缩减成方便被刺的漏洞，也不能把这一击写成更高等级忽然压倒对手。

<a id="recognition"></a>

### 3. 熟悉感与空屋：有可重看的线索，也有后来才知道的事

**匿名旧事先出现，身份后来对上。** 摩天轮上，楚已经想起自己曾陪拉拉队长看电影、陪舞蹈团团长去水族馆，只是把它们当作不懂约会意味的旧例（`lz2:part0098:P0012–P0014`）。病房里，他觉得夏的气息熟悉，却想不起在哪里闻过；她说是旧同学，他仍不记得（`lz2:part0108:P0096–P0099`、`lz2:part0109:P0051–P0053`）。最后夏用发型、校歌和具体经历指认那些女生，楚的回忆与之接上（`lz2:part0136:P0036–P0046`）。前面不只是空白，已有可回看的经历与不合之处；但抹去记忆的机制直到后面才明说，不能声称初读者此前已得到完整解释。

**屋子不是只在结尾突然提供孤独。** 赴约尚未发生时，书中已经写她回家喊“我回来啦！”，回应的却只有风声（`lz2:part0124:P0013–P0015`）。尾声看到灰尘、少量家具和过期酸奶之后，楚才重想她怎样独自学人类生活（`lz2:part0143:P0052–P0063`）。前一幕给读者，楚没有在场。它可与后来对照，但一次无人回答不能独立证明她没有家人，更不能单独推出龙王身份；楚想象的每晚生活也不因此全变成亲见事实。

**结尾的记忆方式有更早的基线。** 序幕已写楚每晚在脑中重过父亲的画面，因为不愿让那个人像从未存在（`lz2:part0064:P0079–P0084`）；末场又明确指出，他此前每天记许多事，却没有一件与夏有关（`lz2:part0136:P0045`）；尾声则让功课多出几件事，并写他知道醒来不会再见病床前那张脸（`lz2:part0143:P0064–P0065`，对照`lz2:part0102:P0046–P0050`）。这是已有习惯在关系结束后的变化，不等于序幕已经预告了具体谁会死，也不表示他已经走出失去。

## 揭示后怎样保留原有的关系证据

早先的救援有夏跃入火中的直接动作，照料有病床边睡着、送汤和楚被提醒后道谢的具体相处（`lz2:part0100:P0072`、`lz2:part0103:P0002–P0004`、`lz2:part0108:P0062–P0073`）。后面她把破坏、救援和病房权限解释为试探、遮掩与接近冰窖的手段（`lz2:part0136:P0061–P0068`）；特别探访许可本身确实早已出现（`lz2:part0107:P0054`），但权限怎样服务她的目标，是后来才补出的联系。

因此，不能因她自认利用楚，就删掉已经发生的救人；也不能因她照料过他，就把她的全部目的认证为爱情。她说自己需要力量、要吞噬哥哥，同时又称他不是食物而是哥哥（`lz2:part0135:P0044–P0049`）。本例能追踪这些话与行动怎样并存，不能替她裁定一个最终、单一的真心答案。

本卷还要求把最后的反证读进去：part0137末一度把芬里厄卷入遗体解释成吞噬妹妹、成为海拉（`lz2:part0137:P0050–P0058`）；后来他吐出遗体，显明只是把她藏在嘴里，仍叫她醒来陪玩（`lz2:part0142:P0026–P0032`）。不能停在前一阶段的肯定判断，再用它解释全部关系。哥哥依赖她的早先讲述有后来可对照的行动；人类家庭的整套说法却不能因此一并认证。

## 沿用已有方法时，这个案例多提供什么

- **把关系放进跨场景的实际安排。** 救援留下住院，住院容纳相处，邀请之后有衣着、地址、日程和犹豫。当前写作若已有类似未完成事项，可以让后场继续处理它；这些连接不要求相处必然变爱情，也不要求赴约必须遭遇死亡。
- **让同一类行动在后来场面改变作用。** 早先接住人、后来背人都在提供实际帮助；共同攻击龙以后再接住她，却让自己进入她的攻击距离。可迁移的是谁当时知道什么、靠近改变了什么，而不是每次亲近都安排背叛。
- **把回收接到下一件事。** 刀改变近身战的结果，钥匙让楚继续走到已经出现的地点，遗屋又让旧的记忆功课增加内容。对照已有P2、P3时，分别看行动条件和后续认识；物件再次出现、同一句再说一遍，本身不等于完成跨章连接。

以上是同一案例的编辑归纳，未新增顶层原则或固定章法。它没有证明作者如何预先写大纲，也没有给出各章必须发生几次转折、多少字回收伏笔的比例。事故日期、年龄与若干设定差异继续按[本卷限制](../books/longzu-02.md)保留；不据此拼精确年表，不将后卷材料补进本卷人物当时所知。

本次补成一条有首尾、可核对的卷内情节线；全书多线如何分配篇幅、跨卷总伏笔表、完整人物生涯与原创写作效果，仍未完成研究。
