# 情节设计：追踪布置、解释与兑现

以下只拆已回读的事件链，不把读完整卷后的知识当作初读者已经知道的内容。没有足够证据时，不推测作者怎样预先规划全书。

需要跨章节追踪选择、关系与回收时，另读[《Ⅱ》楚子航与夏弥的卷内情节线](long-arc-longzu-02.md)。它继续核对P2的折刀交付与持有；下面P1–P4原分析保留。

## P1 同一布置先支持期待，再显露用途：《Ⅰ》的放映厅

**定位：** `lz1:part0011:P0025–P0070`；关联[ch12](../../chapters/ch12-lz1-gate.md)。

| 阅读阶段 | 具体布置 | 路明非怎样理解／后面增加什么 |
|---|---|---|
| 自己准备 | 蒲公英、音乐、告白腹稿 | 他要主动表白，读者知道其期待从何而来 |
| 获得西服 | 赵孟华送来合身衣服，并转述正式着装要求 | 他误以为陈雯雯了解自己的愿望，信心增加 |
| 出现相同服装 | 两兄弟也穿黑西服，说自己是群众演员 | 提供了不完全符合他期待的信息，但他尚未拼起来 |
| 指定站位 | 地上复印纸、不要挡屏幕的指令 | 被解释成致辞安排，也实际决定字符的位置 |
| 放映启动 | 缺字的英文、两兄弟催他站回去、赵孟华捧花 | 角色用途显露；原先的西服与站位不需要被撤销 |
| 身体和花回来 | 关节酸痛、想起袋里的蒲公英 | 揭示不只完成智力谜题，还让先前投入变成损失 |

**可试的操作：** 设计误会时分别写出人物当前解释和场面真实用途，检查同一组东西能否同时支持两者。至少留一项不完全吻合的细节，而不是揭晓时凭空增加关键布置。

**边界：** 初读者可能比主角更早猜到，效果仍可来自看着他继续期待；不必强求所有读者同刻震惊。也不把这种公开受挫规定为所有人物成长的开端。

## P2 已出现的物件，换一个身体条件才兑现：《Ⅱ》的折刀

**定位：** `lz2:part0125:P0020`、`lz2:part0136:P0023–P0036`、`lz2:part0137:P0002–P0017`；关联[ch40](../../chapters/ch40-lz2-tragedy.md)、[ch42](../../chapters/ch42-lz2-jormungand.md)。

**观察：** 前面楚子航从手腕皮套抽出借来的折刀检查自己的血，读者见过物件和携带位置。高潮里村雨毁坏、力量耗尽，战斗转为夏弥靠近后的一段问答；后来拥抱使双方进入近身距离，折刀才成为另一种出手机会。这里的变化不仅是换一把更强的武器，而是交战方式、距离和对方判断改变；正文另交代折刀对龙类有特殊杀伤，近身并非唯一条件。

**可试的操作：** 回收物件时记录“已在哪里出现、当时有何独立用途、为何还在、此刻多了什么使用条件”。把旧物重新拿出来并不自动等于有效伏笔，当前条件要让它有新的作用。

**边界：** 本条没有追溯借刀发生的最早场面，只确认part0125已经建立持有与位置。近身谈话包含亲密和试探，不能把夏弥每个动作简化为只为方便被刺的漏洞。折刀更早的使用、收回、再借，以及杀伤能力的提前交代，见[跨章节情节线的折刀专节](long-arc-longzu-02.md#knife)。

**相近写法的区别：** [《商博良Ⅰ》水下绳索](../books/shangboliang-01.md#rope)并非缺少求救工具，而是已有割绳预案使人物抓到绳子仍不敢扯。折刀例看当前怎样获得出手机会，绳索例看工具可用时人物怎样预判他人的回应；完整过程留在卷内，不把两者合为一条物件必救场的规则。

## P3 正事结束后，留出认识的过程：《Ⅲ下》的遗物

**定位：** `lz3c:part0368:P0019–P0033`；因果核对另见`lz3c:part0368:P0005–P0010`、`lz3c:part0368:P0034–P0037`；关联[ch100](../../chapters/ch100-lz3c-sakura-rage.md)。

**观察：** 结局已经发生，文本仍花时间让路明非逐项看箱中物。明信片补上她如何记旅行，手机补上她也在看他，标签补上共同拥有的范围；三项不是同一个事实的三次复述。开箱前他已毁坏圣骸并想获得复仇的快感；看完遗物后，他提出用下一个四分之一生命交换杀死赫尔佐格的具体交易。这里能确认关系认识得到补充、交易随后提出，不能说复仇动机由这些发现才产生，也不能把新认识认定为交易的唯一原因。动作高峰与认识高峰可以错开。

**结尾决定怎样通过问答变得具体：** `lz3c:part0368:P0032–P0037`先写吼叫、退后和很久才恢复平静，再让路明非低声提出交出下一个四分之一生命。路鸣泽问是否要复活女孩，并重申不能改变过去；路明非接着把要求明确为杀死赫尔佐格，提出融合方式。对方又说这一力量不足以杀敌，他没有撤回要求，而是让对方尽力、剩余部分由自己承担，并看向源稚女，提到对方以命相托。问答依次呈现交换什么、要达成什么、已提出的办法有什么限制、自己还承担什么，不是吼叫后直接宣布获得足够力量。源稚女的托付也进入他当场给出的理由，继续限定了“遗物发现单独造成交易”的说法。

这段还与开头`lz3c:part0368:P0002–P0004`只能改变未来的说法接上；`lz3c:part0368:P0038–P0042`才由路鸣泽回应并进入融合变化。恢复平静和低声说话是可核对的排列，不能据此认证交易理性、公平或足以成功。若概述为看完遗物便换取力量，事件先后仍在，但会省掉问答中重申无法复活、明确复仇目标、指出力量不足及人物承担剩余部分的过程；这是对压缩所失内容的编辑比较，不要求所有决定都写成多轮谈判。整场动作与他人的介入见[D4](close-reading-description.md#d4-翻面才看见的细节ⅲ下的玩具)，发现中的词句推进见[C4](close-reading-character.md#c4-简单记录形成个人表达ⅲ下的绘梨衣)，共用同一场证据。

**可试的操作：** 重大事件后若还有人物尚未理解的关系，可先给一件能独立增加信息的东西，再决定是否需要第二件；让发现影响下一次选择。这里不要求再造一个身份反转。

**边界：** 不是每次死亡都需长篇整理遗物。若前文没有相处和物件基础，临时塞入记录会显得替人物补写人生。与[描写D4](close-reading-description.md#d4-翻面才看见的细节ⅲ下的玩具)共用证据，分别讨论揭示顺序与观看动作，不计作两条独立发现。

**对照补证：** [《上海堡垒》旧手机](../books/shanghai-fortress.md#messages)也通过记录增加事后认识，但容量限制使人物须删除旧信息、等待再接收。它补充发现怎样经过操作，留票事实与仍未知的心意分开；不把重复机制计为新方法。

## P4 重复段落按变化分配篇幅：《Ⅳ》的重试

**定位：** `lz4:part0425:P0002–P0013`、`lz4:part0426:P0052–P0057`；关联[ch113](../../chapters/ch113-lz4-father-traces.md)、[ch114](../../chapters/ch114-lz4-borrowed-monkey.md)。

**观察：** 第62、77次等重试只给局部办法、意外和失败结语，跳过相同路程；重复的关卡标头帮助读者重新定位。第91次之后，篇幅转给醒来、吊扇、回想诺诺临死前的神情和他对重来的认识。后一次不只再提高难度，而是改变了失败对他的意义。

**可试的操作：** 连续尝试时，先标记不变条件，重复部分用读者能认出的简短信号；篇幅留给办法变化、意外结果或人物认识改变之处。若每次都完整重演开场，变化会被淹没。

**边界：** 这是幻境重试的叙述组织，不把梦里表现当现实已掌握的技能，也不把小说里的医疗安排作为现实做法。普通训练段能否这样压缩，仍看读者是否需要某次完整经历。

这些片段支持局部场景和段落设计；尚未完成逐卷伏笔总表或完整人物弧线，不能声称已经还原作者的长篇规划程序。
