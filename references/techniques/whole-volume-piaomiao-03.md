# 整卷结构个案：《天下名将》的叙述重心与跨章后果

本例按原顺序回读《九州·缥缈录Ⅲ：天下名将》全卷五章，讨论大局推进与局部展开怎样配合，以及前事留下的状态怎样成为后场条件。它补[楚夏线](long-arc-longzu-02.md)的一条关系线和[“殇阳血”专题](multi-line-piaomiao-03.md)的一段战役，不替换原章节与TJ1–TJ7细读，也不把共用原文算作新增独立证据。

来源为`pm3`，正文`part0498–part0502`共2691个非空块、158814个规范化字符；含五个标题与标点，不含版权、目录、锚点和换行，不是纸书页数或纯汉字数。本轮33块顺序回读、原文与reader及来源指纹核对记录保留在研究工作目录；打包范围不含小说全文和本机阅读材料。版本、锚点规则与原始指纹见[本卷说明](../books/piaomiao-03.md)及[清单](../../sources/piaomiao-03-manifest.json)。以下是文本观察和编辑比较，不推测作者起稿时的大纲，未验证原创写作效果。

按问题选读：[展开与略写](#allocation)、[跨章状态延续](#continuity)、[准备与后来解释](#preparation)、[适用范围](#limits)。

<a id="allocation"></a>

## 一、大局持续推进，不要求每段都以大局为叙述中心

离军归国与联军围堵，从开篇弃帝都延续到末章突围，组织了军队集结、战期、移动和卷末结果。少年出征、求功、求生与护友则反复成为近距离展开的中心。帝室、当阳与秘术来访有的实际改变军令，有的只留下尚未完成的事项；不能都称作服务决战的伏笔。

| 全卷顺序与字符数 | 怎样分配叙述 |
|---|---|
| 乱世之狮，33783；`pm3:part0498:P0001–P0558` | 历史、退城、朝廷与白接消息（`pm3:part0498:P0001–P0124`，共7895字）后，转完整修枪；赌局与街斗之间穿插军备和叔侄夜行，授职讲解之后又转家中告别与朋友来接。大任务已提出，日常仍有自身后果 |
| 初阵，31929；`pm3:part0499:P0001–P0574` | 三方出发各有私人要求与服从对象。嬴息决斗及主阵交锋`pm3:part0499:P0204–P0348`共9085字；随后姬伏击、受困、接刀与脱险`pm3:part0499:P0349–P0570`共12562字，个人困局成为长时间跟随的对象 |
| 军之王，24448；`pm3:part0500:P0001–P0438` | 病车、喂药与坦白`pm3:part0500:P0064–P0138`占4148字；之后交替写阵前救人、军议、秘密备毒、敌帐对弈、巡城听箫，最后把约战消息传到华处。准备期不只列筹划步骤 |
| 神之使，29832；`pm3:part0501:P0001–P0484` | 前段华柳、朝议与驳回复信接起过境问题；犬狼异状至雷入离帐`pm3:part0501:P0146–P0484`共20675字，是同一次来访在小兵、少年、联军和离军处逐步显出的影响，不是四条等量新线 |
| 殇阳血，38822；`pm3:part0502:P0001–P0637` | 父子会面、诸将等候与白的私谈在出战前展开；战斗转入营地后，`pm3:part0502:P0436–P0524`连续6223字写谈话、袭营、救友、失控与抵达救援，随后才回主阵结断后者和追射之事 |

这些数量只用于比较本地版本各段的实际分量。同一段可兼有军务、处境和关系作用，不重复累计成几条线的独占篇幅，也不据此要求主线、人物或日常占固定比例。

### 先留下大任务，再让另一件事完整发生

赌局不是几句轻松插科：下注升级、作弊败露，接到追逐、老师介入和罚没赌资（`pm3:part0498:P0229–P0293`、`pm3:part0498:P0337–P0399`）；到朋友来接，吕的钱仍受罚没影响（`pm3:part0498:P0540–P0547`）。但后续授军职有另一套出征安排，不能把时间接续解释成赌博闯祸的奖励。

初阵主阵暂告一段时，息问姬在哪里，下一段才转姬的伏击（`pm3:part0499:P0347–P0350`）。随后不是按固定间隔切回主阵，而是连续追到他受困、重伤与获生。若只概述为初战扬名，会少掉后文仍在使用的伤势与恐惧；这是对删减结果的编辑比较，不是已验证的读者反应。

### 相同经过可以略写，局部危机也可以暂不切回

华柳六日阵谈由几句概述，再详写当前有关过境、护白与赠书的这一回（`pm3:part0501:P0009–P0056`）。末战以几条军报概述半夜鏖战（`pm3:part0502:P0367–P0371`），随后详写古月衣封东侧、被嬴压制及息救他（`pm3:part0502:P0386–P0426`）。这给[P4重复中的篇幅取舍](close-reading-plot.md)补不同情境，不另立略写战斗的规则。

营地段则先连续写到生还与军情解释，再返回主阵交代苏元朗未能撤走。这里的完整跟随与不同结果已见[战役专题](multi-line-piaomiao-03.md#convergence)；全卷比较增加的是它在此前照护、留营和军队移动中的位置，不重写一套切场方法。

## 二、补证：状态延续怎样具体改变下一场

[ch21](../../chapters/ch21-lz1-sins.md#方法与原因)已有成本影响后续行动，[楚夏线](long-arc-longzu-02.md)也已有救援留下住院和相处条件。本例把同一身体限制追过数章，不另命名新机制。

| 前事与来源 | 后场实际继续处理什么 | 因果与解释的边界 |
|---|---|---|
| 姬仍选择伏击，部下死亡：`pm3:part0499:P0349–P0409`；拒财：`pm3:part0499:P0437–P0445` | 脱围后仍遭追，后又被离军本队阻住 | 部下明确提出可以撤；姬亲述不拿钱因同伴已死。人物解释有原话，不等于他独自决定了对手怎样回应 |
| 接刀后断臂等伤：`pm3:part0499:P0515–P0538` | 下一章身缠木枝夹板、不能抬头，需别人喂药：`pm3:part0500:P0050–P0051`、`pm3:part0500:P0071–P0080` | 可直接核对伤势限制与照护动作；不是仅以一句受伤证明代价存在 |
| 车中照护、器械经过，发问被打断后续接：`pm3:part0500:P0070–P0138` | 两人独处后主动约保密、透露家庭恐惧与怕死 | 伤势提供共处条件，坦白还依赖发问、倾听与主动透露；不说重伤必然制造信任，局部对白组织仍查[TJ2](../books/piaomiao-03-close-reading.md#tj2-不是重复口头禅是上一个问题还没得到回答) |
| 马惊时守军被召走，吕本想跟去：`pm3:part0501:P0233–P0245` | 方提出姬不能移动、需要照看，吕想到姬而同意留下 | 原文明示前章状态进入当前决定；不证明后来袭营是这次留下造成的，也不证明秘术来客专为两人来 |
| 末战退军经过营地，吕想起不能动的姬并出刀：`pm3:part0502:P0455–P0493` | 姬仍受夹板约束，却用单臂爬离危险，打醒吕并收开影月：`pm3:part0502:P0504–P0515` | 吕先藏身、后才记起同伴，救人后又失控；姬不是只能等救，伤口也仍会迸裂。具体承诺触发见[TJ6](../books/piaomiao-03-close-reading.md#tj6-承诺有了具体触发兑现仍带来失控) |

这条状态延续与军队撤退路线在末章相遇。退军由主阵突围而来，怎样造成营地危机见[路线后果](multi-line-piaomiao-03.md#camp)；不能用姬一次求功包办整条军事因果。伤势、既定军令、人物选择和外来危险各有作用。

## 三、补证：准备分次显出，不等于全过程早已交代

这部分接[观察、解释与后证](../../patterns.md#观察解释与后来的证据)及[卷三的拒毒与用毒区别](../books/piaomiao-03.md#后文怎样限定前面的理解)，不增加计划检查流程。

| 阅读顺序中的证据 | 原文支持什么 | 尚不能确认什么 |
|---|---|---|
| 白散会后听取炼药与备人报告：`pm3:part0500:P0279–P0282` | 读者先知道他有其他毒药准备，区别于公开否决尸毒 | 实际怎样找到泉源、怎样投放没有在此展示 |
| 决战夜医官查井、报告中毒与失去战力：`pm3:part0502:P0158–P0181` | 水中有毒，离军身体状态受影响，与前章准备相接 | 军报口径不完全相同，不自行合成精确病理统计 |
| 谢说也许早探泉脉、据说藏有大量卷宗：`pm3:part0502:P0183–P0187` | 对意外的解释来自谢，且明确带保留词 | 不能认证白确实提前勘探了一年，也不能替文本补写全部执行过程 |

等待期并非只有同一个问题原地重复：敌方推演、华请求过境、朝廷拒绝与秘术来访都在发生；但这不证明它们出自共同总策。至风到出令（`pm3:part0502:P0124–P0137`）、烟攻改变防守条件（`pm3:part0502:P0215–P0230`），才看清另一部分执行。原例可供比较读者先知道哪些准备、后来才见什么效果；不要求所有作品都延迟说明，也不将后补解释一律判成失败。

## 四、怎样选用，哪些仍未完成

需要决定整卷哪些场面展开、哪些略写时，可比较本例的大任务与局部重心：前者持续并不要求每段都报进展，后者也不能靠重要二字自动获得长篇幅。当前场面仍需有可跟随的处境、相处或感知；没有类似任务与人物条件，不搬用战争的规模和节奏。

前事确实留下持续限制时，可参考它怎样改变后续动作、共处与去处；没有这项限制，不为套用而硬造重伤。两线有真实通信或行军路径时，再查影响怎样传过去，不强求所有支线都反过来决定总胜负。

未在本卷完成的事项继续保留：华因约战上表、朝廷驳回和华收到答复均已发生（`pm3:part0500:P0427–P0438`、`pm3:part0501:P0057–P0117`），护白可违诏仍是表态，末章只写到允许华茗留下。雷的全策、小舟归属、花能否在楚卫开、白留信后果及母亲真相都未补完；长公主还亲口承认失算、雷不在谋中（`pm3:part0502:P0593`、`pm3:part0502:P0618–P0619`）。

这些区分用于读准这个案例，不是一份要求每个长篇满足的清单。全卷个案没有建立跨卷总伏笔表、完整人物生涯、作者独有章法或成稿改善结论。
