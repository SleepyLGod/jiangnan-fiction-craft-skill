# 句间与段落组织：五组局部细读

回到本地原文，看衔接、句子长短、说明位置与段尾。S仅作查找编号；这些片段与原有L3、D1、TC2、TY11、YM8共用证据，不是五种新框架，也不计五份独立佐证。原分析保留。

“原文排列”描述可核对的文字顺序；“编辑比较”讨论删、移或合段可能改变什么，不是原文异本、作者起稿过程或已验证的修改效果。下文段落边界已核对本地HTML/XHTML的p块，不代表其他版本的排版。

句长与分段分开看：前者比较句子的长短与拆并，后者比较段落边界与段间转接。同一句另起一段，句长未变。

## S1 机械接到身体：衔接有旧词，也有感受变化

**定位：** `tz1:part0545:P0031–P0038`；接[TC2](../books/tianzhichi-01-close-reading.md#tc2)。短引：“与此同时左肋下方那处瘀青也越发疼痛起来”。

**原文排列：**

| 位置 | 句子或段落怎样接上 |
|---|---|
| P0031→P0032 | 前段说贵族少女不愿接触机械，后段以西泽尔“却和机械很亲近”转到他；拆、上油、组回先给动作，再给运转微声 |
| P0032→P0033 | “西泽尔自己”“也像是这样一件机械”承接刚修好的东西，把流畅与冷硬转用于人物给人的感觉 |
| P0034 | “这方面的天赋”回指维修，解释勤工俭学的来由；工作仍接在已写出的能力上 |
| P0035→P0036 | 先脱湿校服、走入淋浴间，交代热水；接着写冰冷身体变柔韧，感知对象才从机械转回身体 |
| P0036→P0037 | 黄油微融以后，同一句以“与此同时”接肋伤变痛；下一段才补先前重击、未检查伤口与螺丝刺入的情况 |

**细读与编辑推断：** 衔接不只是反复写名字。“却”建立前后对照，“也像是这样”借用刚形成的机械印象，“这方面”回指已发生的动作；脱衣、热水又让新的身体感受有来路。冷的原因以“因淋雨而冰冷”先交代，伤痛的具体原因则后补，说明并未采用统一位置。

P0032内部也有句长变化：开头用较短的一句先说他与机械亲近，第二句沿拆解、上油、组回展开，第三句再写调试结果。短句先定关系，较长的动作句把这份亲近写成实际接触，而不只是增加几种评价词。

P0036没有在黄油微融处结束，而在同一句里继续写疼痛：舒适出现时，伤也被感觉到。这里可以确认的是两种感受同时呈现，不能进一步说身体变软就代表人物性格变温暖。

**编辑比较与适用条件：** 如果先完整交代伤因，再写热水，读者会先带着伤情知识经历洗澡；原顺序是先感到痛，再知道此前漏查了什么。两种次序都可成立，区别在于先提供哪层认识。把疼痛另起一句，也不必然更差，但会多一次句号停顿；不是保留“丝绒、黄油、刀片”几个词就保留了原来的衔接。适合原本就有湿衣、热水与旧伤这些连续条件的场面，不要求每次转场都连用比喻。

## S2 长段心声后独立六字：短下来的是判断，出口仍会卡住

**定位：** `lz3b:part0245:P0058–P0071`；接[语言L3](close-reading-language.md)。短引：“只是爱，不后悔。”

**原文排列：** P0058–P0061逐一想起熟人的爱情又排除；P0062转为一整段想象，以两次“未必要”排除完美和好结果，再经“但多年之后”展开重逢，接连写“忽然”的反应。P0063把六字判断独立成段。P0064回到寂静大厅和满头热气，P0065给同伴担心，P0066才是真正说出口的回答；其中有省略号、说得慢和再也憋不出字的说明。P0069又换成店长的大段阐释。

**细读与编辑推断：** 六字短段承接前面已经经历的排除和想象，不负责再讲一个爱情故事。它结束这一轮内心组织，下一段就把注意带回房间和身体。读者知道的完整想法，与同伴能听到的话，因而不相同。

这里须区分句子短和表达断续：P0066整段并不短，但引语里的停顿和叙述中的卡住，让出口显得艰难。相反，P0063短而完整，却不是他当众成功说出的一句台词。不能把二者一起概括成“关键时刻用短句”。

**编辑比较与适用条件：** 将六字并入P0062，判断内容仍在，但独立成段的停顿消失；若只保留六字、删掉前面的想象，则少了这次压缩所承接的内容。两种改法都不能仅凭字数判优劣。可用于确有内心与出口差异的场面；已有L3处理表达受阻，这里只补段落分隔与长短转换，不另立人物类型。

## S3 起身的原因先澄清，问饿的旧事后说明

**定位：** `tz2:part0688:P0004–P0020`；接[TY11](../books/tianzhichi-02-close-reading.md)。短引：“昆提良可不是有意要慢慢起身的”“这是艾莲和昆提良之间的细碎往事”。

**原文排列：** P0004先由艾莲看见昆提良慢慢起身，军服和骑士徽章进入视线；P0005紧跟着澄清不是故意放慢，而是膝盖发软、身体哆嗦。P0008–P0009说明她担心他回来炫耀还是只想再见，随后才给结巴的问答。P0015问吃过没有，P0016让唐璜在心里嫌这话不会叙旧；P0017–P0018先给艾莲微笑、坐下吃的实际回应，P0019再补夜班里互留食物的过去。P0020返回当下聊天和唐璜的无事可做。

**细读与编辑推断：** 起身的解释紧跟动作，且放在问答之前，使读者先知道他的紧张；艾莲仍在猜他的来意，不能把读者所得自动算作她已知道。共同夜班的解释则等回应发生后才给：读者先看见一句平常问话接通了关系，再获得唐璜不知道的理由。

P0019的往事不是只贴一个“他们曾经很亲密”的标签，而写忙到深夜、留食、躲着吃、继续做事；段尾停在同处巨大空间却偶尔相逢。解释到这里已有具体生活内容，下一段再恢复眼前的聊天，没有继续把这句问话认证为普遍有效的情话。

**编辑比较与适用条件：** 若把夜班往事移到P0015以前，读者可以先懂问饿的意义，再看唐璜误会；原顺序让理由后到，两人的回应先到。若推迟P0005，起身原因的澄清也会延后。这是信息时点的区别，并非后置说明总更含蓄。可用于叙述者有权限交代各人心思、人物间又确有共同经历的场面；限定视角作品须先核对这段往事从何得知。

## S4 红色先流过一整段，“是血”才接进下一段

**定位：** `pm5:part0520:P0402–P0411`；接[YM8](../books/piaomiao-05-close-reading.md)。短引：“此刻这条河也依旧平静，一点事情也没有发生。”“那层冰是活人和死人的分界。”

**原文排列：** P0402由透明冰层和昨日的小鱼写到此刻无事，段尾暂留在平静；P0403用一声指向上游的喊话打断。P0404较长，接连写红色出现、推进、人物走到河中、红色卷到脚下，再向下游而去，段中始终没有直接命名为血。P0405由短对白点明，P0406才接“多少人的鲜血”的问与无人知道的答。P0407再写一具尸体漂来、眼睛似乎看人、阿苏勒按冰，P0408以一句判断独立成段。P0409–P0410接记忆与归乡，P0411才换到上游的命令。

**细读与编辑推断：** P0404反复保留红色这一可见对象，动词改变它的位置；不是每个分句另换一个漂亮称呼。段尾停在水流继续走，下一段才命名，形成先跟随所见、再得到解释的顺序。读者可能提前猜到是血，不必把它夸作人人都会受骗的悬念。

长段之后的短对白负责辨认；稍后的独立短段则把按冰这一动作概括为生死分隔，二者虽然都短，作用不同。P0408也没有包办全部情绪，下一段仍让尸体漂走、记忆与身体反应继续发生。

**编辑比较与适用条件：** 若在P0404开头就称血水，颜色推进和空间距离仍可保留，但辨认不再留到下一段；若删去按冰，只留生死分界的判断，则少了看得见却被冰隔开的动作依据。适合确有视线、流向与阻隔的目击场面；不因此规定惨烈场景必须先隐去血字，或短段必须升格成格言。

## S5 段尾从风声转到最后一次，空下来以后另起道歉的念头

**定位：** `cijian:ch75:P0002`、`cijian:ch75:P0008`、`cijian:ch75:P0011–P0016`；接[描写D1](close-reading-description.md)。短引：“不过也许已经是最后一次”“影子终于淡去了，淡去了，直到心里空空如也”。

**原文排列：** P0002第一句跟风走过地面、灌木和叶声；第二句从听见什么转到乔峰第一次感到这样的风声，末尾才接“不过也许已经是最后一次”。P0008明确他明天毕业、以后不会再走这条路。P0011–P0014另经身体酸涩、女孩敲头的记忆和摸头而笑，P0015才让风与影子回来，以两次淡去接到心空。P0016单独放想给阿朱打电话道歉的话。

**细读与编辑推断：** P0002的尾部没有再添一种景物，而改变前面风声的时间意味：日常声音第一次被认真听见时，离开已经临近。“也许”仍在，不能改述成这是人物最后一次听见任何校园风声。

P0015的重复让淡去有延续，不是从一个动作直接跳到“他很悲伤”；“直到”把这一段收在心空的感觉。道歉的念头另起一段，使情绪的余下部分与眼前还可回应的关系分开呈现。原文写的是想打电话，不能从此补出已经道歉、已经放下或关系已经修复。

**编辑比较与适用条件：** 如果P0002止于叶声，读者仍能得到安静校园，但段内不再带出这次聆听与离开的关系；如果把道歉念头接进P0015同一段，信息未必减少，情绪与下一步意向之间的分隔会改变。可用于时间条件已成立的回望，不要求每段景物都以失去收尾，也不要求每段情绪后立即采取行动。
