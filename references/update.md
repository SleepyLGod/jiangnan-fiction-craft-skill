# 来源、引用和后续更新

## 当前覆盖与定位

版本0.1.0只基于《此间的少年》本地EPUB，正文十章及后记已全文阅读。目录有76个导航条目，含一个无文字的封面及75个文字条目。ch1是标题与编制说明；正文从ch2开始；后记在ch75中。76不是纸书页数，自动提取识别的15章也不是实际主章数。

封面图没有分析；本地文件含整理声明与水印，出版版本、ISBN和与纸书逐字一致性未核实。本 skill 说明的是这份文字版本，不作作者全集或版本校勘结论。对话中提到的《龙族》《天之炽》尚未阅读纳入，无占位分析。

来源清单在[manifest](../sources/cijian-manifest.json)。`cijian:ch31:P0041–P0045` 指此EPUB的 `OEBPS/ch31.html`，按HTML body顺序提取、合并段内空白后的第41至45个非空块。它不是纸书页码；另一个版本的段号不能直接套用。配套本地reader文件P0001在第4行，此后每段一行。

需要重新确认锚点时，定位同一指纹的本地源文件及配套reader；文件不可用就说明未重新核对。

观察、推断、建议分别表达：

- **文本观察**：什么人物在什么场面做了什么，有锚点可查。
- **编辑推断**：这个安排可能造成怎样的阅读效果，有竞争解释时保留。
- **应用建议**：在什么写作问题下可试用，怎样失效。

人物的格言、作者按语和叙述者评论均不自动成为外部事实。日记的取得时间、含混的未来女孩等未说明之处保持未知。

## 加入下一本书

用户提供或指定新作品后，使用同一个 `jiangnan-fiction-craft`，保留旧证据和有效结论，不从名称猜测新书内容。现有的十个 `chNN-cijian-*` 文件保持稳定；下一本书可以按转换器Fold-in继续编号，并带独立书籍标识，避免把不同书的“第一章”混为一谈。

1. 核实书名、作者、版本可辨认信息、文件指纹、目录和实际提取覆盖；长系列要逐卷记录，不用读过第一卷代表全系列。
2. 明确本次范围和用途。未读完整便写“选读”，不要将抽样提升成全文规律；需要全文分析时补完再更新覆盖状态。
3. 给新作品独立来源ID、锚点规则与清单。新增分析仍写具体场景、机制解释、适用条件和反例，不复制长段原文。
4. 比较旧结论：新证据是在不同题材下复用，还是限定了适用范围？例如本书怀旧校园的幽默，不足以说明战争场面的笑料也应同样安排。
5. 核心规则只吸收确实改变写作决策的结果。某方法只在一书出现便保留该标注，不为塑造统一作者形象消除矛盾；保留各书不同的叙述人称、距离和时间结构。
6. 更新版本、书目覆盖、主章与主题索引。新增来源可升0.2.0；局部澄清可用补丁版本。版本号是本 skill 的维护约定，不是文学研究标准。
7. 检查全部链接、引用位置、来源未改动与生成文件扫描；需要试用时在独立临时样稿里做，不擅自改现有小说或安装到其他目录。

这是一套可积累的阅读与改稿参考。它不能仅凭“文件格式通过”保证新正文有趣、符合原型或适合漫画；这些需要实际样稿与读者反馈。
