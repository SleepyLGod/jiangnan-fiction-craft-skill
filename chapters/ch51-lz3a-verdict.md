# 51 王的裁决：计划有遗漏，守约需要承担实际风险

范围：《龙族Ⅲ：黑月之潮（上）》part0160、part0161。以下方法为编辑归纳，不是作者自述理论。

## 文本观察

邦达列夫枪杀博士，原定撤走的孩子也被放弃。他实际要龙骨，并知道新技术可以解决博士以为不可解决的挖运问题。雷娜塔救出零号，黑蛇声音破墙、犬群循味找来，脱出港口仍没有方向和家。锚点：lz3a:part0159:P0023–P0055。

犬项圈的发射器使追踪者靠近，零号并未掌握所有条件。女孩解开狗的套索，反让自己显形；她不跑向零号，以免暴露他。分析武器的潜能觉醒也没让旧枪正常射击，最后零号绕开故障枪身。锚点：lz3a:part0160:P0022–P0058、lz3a:part0161:P0016–P0033。

零号承认原誓言只到有用为止，因为她真守约而内疚，重新许诺仍留着条件。取走茧后认为骨骸不再危险的判断，也被召醒飞起的巨骨推翻。锚点：lz3a:part0161:P0002–P0015、lz3a:part0161:P0034–P0061。

## 方法与原因

**准备先有效，再受未知条件限制。** 犬群确实找到女孩，项圈却带来追兵。先保留准备的收益，再写意外成本，才能区别合理计划有遗漏与计划完全没用。

**区分会用、器材可用与成功。** 角色理解结构不等于旧机器可靠；补救应绕开具体故障，而非再喊一次信念。守约的分量也来自她有逃向同伴或独逃的选择，却为不暴露他留在原地。

## 场景拆解与原创应用

逃出封锁 → 跟踪源暴露 → 放犬导致自己显形 → 觉醒仍遭机械失效 → 同伴介入 → 新誓约 → 另一人的安全结论被后证推翻。

原创示例：女孩学会船桨动作，旧桨却在急流中折断。她此前绑好的拖绳还在，同伴利用绳绕过断桨把船拉近；训练没有被宣布无用，救援也不是凭天赋凌空完成。

## 使用条件与失败方式

适合逃亡和互相保护。零号重新救援不等于先前胁迫已被赦免，少女守约也不证明所有条件誓约都值得遵守。武器参数、尸骨活动和温水复生仅按小说发生记录，不复刻武器改装，不发明医学解释。
