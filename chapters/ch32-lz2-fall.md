# 32 中庭坠落：一场救援需要不同人的局部知识

范围：《龙族Ⅱ》part0098–part0100。

## 文本观察

楚把摩天轮当培训空间，夏把它当可能的约会；他懂书本上的心理，却不懂当下话语。等上过山车，强战力的楚也会害怕，正因害怕先查过结构。父亲保护孩子的面容又触发他的行动。锚点：lz2:part0098:P0004–P0081、lz2:part0099:P0002–P0014。

魔鬼给路短时交易窗口，昂热的动作打断它。时零不是让全部世界钟表停下，而是加快特定人；维持者流鼻血、有即将昏厥的限制。普通乘客不能自己爬走，救援目标是全车。锚点：lz2:part0099:P0015–P0066、lz2:part0100:P0002–P0015。

螺钉的危险由会员卡被穿透显明。坠轨刺穿水管，水又抬起钢骨，补救产生新障碍。路知道点火会伤楚，先拒绝后依其要求执行；楚爆血、昂热维持、夏在最后改变坠落轨迹，完成不同环节。锚点：lz2:part0100:P0016–P0072；夏后述见lz2:part0102:P0046–P0083。

## 方法与原因

**让恐惧也产生可用知识。** 怕乘坐，所以先查；不是先塑造胆小，再毫无来由地赐予知识。临危时仍需说明他知道哪部分、不知道哪部分。

**用可见试验代替抽象危险。** 螺钉看似缓慢，卡片被击穿却改变路的判断。选一个小物承受真实后果，让理解成为下一动作的前提，而非只加专家的高声警告。

**把服从也写成经过判断的选择。** 路并非一直呆看。他有拒绝的理由，听见承担者要求后改选，参与了不可回避的风险。团队戏不要求每个人火力相同，却要有各自不能省略的工作。

## 场景拆解与原创应用

培训和约会意图错位 → 强者也害怕 → 游乐设施失效 → 魔鬼提供交易 → 另一能力争得有限时间 → 技术知识设计方案 → 小物验证危险 → 方案造成连锁障碍 → 队员承担不同环节与伤害。

原创示例：缆车停在半空，怕高的检修员记得制动器位置，摄影师用镜头看见断口，乘客负责将绳索送到下一节。有人不愿拉动会伤到同伴的锁扣，需要听清替代办法为何已不存在。成功后保留伤势和责任，不用“配合完美”清零。

## 使用条件与失败方式

适合限时群体救援。技术细节必须支持小说因果，但这里的电气、动力和医学叙述不是现实操作指南。夏是否出于纯粹好意在后文被重新解释；当前先记录实际救下和本人说法，不提前确定全部动机。
