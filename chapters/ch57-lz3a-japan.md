# 57 日本分部：受过伤、做过恶和最后的善意不能互相抵销

范围：《龙族Ⅲ：黑月之潮（上）》part0171、part0172、part0173、part0174、part0175、part0176。以下方法为编辑归纳，不是作者自述理论。

## 文本观察

执行者用详细财务资料逼医生供出药物流向，取到名字后也没有立即安全放人。被追捕的樱井明自幼囚禁，曾长期压住冲动，后来用药换得短暂力量，同时连续加害他人。受害经历说明处境，不免除他自己的责任。锚点：lz3a:part0171:P0002–P0066、lz3a:part0172:P0002–P0023。

他与“小圆”的猫与冒险故事交谈，最后明知人质有利仍放她走；但女孩实为成年执法人矢吹樱，猫盒和整套身世是长期预备的道具。被触动的反应可以真，触动他的故事却不一定真。源猜放人缘于爱情，练习本又给出另一解释。锚点：lz3a:part0172:P0024–P0064、lz3a:part0173:P0003–P0060、lz3a:part0174:P0002–P0061、lz3a:part0175:P0005–P0032。

源烧掉本子、说无需理解，随后仍质疑自己的执法资格；养父以使命压住疑问，另筹消灭神葬所。锚点：lz3a:part0175:P0050–P0068、lz3a:part0176:P0002–P0042。

## 方法与原因

**用不同证据分别支持不同判断。** 囚禁支持他被限制，杀人支持他加害，放人支持残存选择；不要用最后一项覆写前两项。故事中的权威可以解释，但叙述应给读者看其解释之外的物证。

**让伪装有准备的时间。** 对方以“来不及做道具”排除嫌疑，后文揭示长期预制，误判就有具体原因。反转应改写线索含义，不能凭空宣布所有线索都假。

## 场景拆解与原创应用

被监控 → 接受诱惑 → 加害 → 被交谈暂时触动 → 放弃人质 → 执行处刑 → 伪装揭示 → 执法者拿本子重新理解，却仍压下问题。

原创示例：逃犯放走给他讲旧校故事的乘客，后来发现对方是调查员。故事预备过不取消他放人的选择，放人也不取消先前受害者；让两种真相都影响后续判词。

## 使用条件与失败方式

适合复杂加害者、伪装与执法冲突。只记非图像化暴力事实。所谓自闭症少女整套人格是伪装，不能作医学案例。樱井是否爱上对方、是谁替他写深刻句子仍有解释余地；历史、药理和黑道规则不当现实资料。
