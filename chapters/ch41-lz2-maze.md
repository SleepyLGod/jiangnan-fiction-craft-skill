# 41 迷宫：让规则在再次选择时接受检验

范围：《龙族Ⅱ》part0128–part0132。

## 文本观察

路不上鬼车、塞耳塞，看似合理自保，却失去保护并听不见危险；驱雄性骨鸟的香料也防不住女皇。楚不进车厢是为长刀留空间，落石又迫他进入。两人办法各有依据，不是简单胆小或莽撞。锚点：lz2:part0128:P0048–P0086、lz2:part0129:P0002–P0030、P0069–P0098。

楚建模本来未成，幕后替其输入结果又清参数；他仍查出夜间震动与线路重合。风火合击消敌，却毁掉列车造成新负担。背夏、交箱和检修车接续身体与物件状态。锚点：lz2:part0128:P0020–P0047、lz2:part0130:P0002–P0022、lz2:part0132:P0002–P0024。

牌局以孤独作筹码，瓶盖比金币贵。高幂先想踩别人带女友走，后来主动输光托付。路本可独自赢，却试着分给万博倩；荷官突然会弃牌，原观察不再成立。万再以自身诱其贪欲，选择回找高。锚点：lz2:part0130:P0029–P0093、lz2:part0131:P0002–P0045。

## 方法与原因

**把行动依据与客观规则分开。** 先说人物为何这样选，再让结果检验；有效一段的办法不必永远有效。检查反例来自先存条件、难度改变还是未被理解的机制，不能混称人物变蠢。

**让利他不是说一句就完成。** 路先有可独自逃的机会，再延后获胜、让渡筹码，规则变化后继续考虑别人；万也有自己的返回选择。每个人都应有能够牺牲或保留的东西，不只等主角救。

**保留合作的连带成本。** 风火消灭敌群也毁交通，拥抱减少孤独也减少筹码。代价由已建立规则产生，才不显得作者额外惩罚善意；并非所有好事必须带苦果。

## 场景拆解与原创应用

自保反造成暴露 → 重新上车 → 明白规则和价值 → 依规则试玩 → 别人的私心显形 → 主角获优势却想分享 → 规则外推被反例打破 → 另一人主动改变策略 → 出口仍有后续路程。

原创示例：洪水避难点按等待时长分救生艇名额，两名家人愿互相照顾却因此错过登记。工作人员先只想送走自己人，后来让出位置。主角不能靠一句“大家都走”增加艇数，需要让另一个人决定留下联络。写代价时保留制度可被质疑，别把残酷规则当天然正义。

## 使用条件与失败方式

适合有规则的比赛、困境和协作。德州扑克概率与神话解释只作虚构材料。楚有外部帮助不等于未做推理；万的前途由路想象的部分须标明。杀看门人不等于已经回家。
