# 167 魔神归来之夜：具体写法、条件与后果

## 文本观察

外廊庭院、侧门和曲折通道先前已有，步兵封路又退、烟火与爆声改变视听。同一教堂先护人、又困人、再阻军；匪与师生暂并肩不等道德和解，军人准射、匪乱射仍留训练差。西一直握妹仍被人流冲散，同色校裙加烟遮使寻人难，不是为了危机突然松手忘妹（`tz1:part0577:P0002–P0060`）。

拜伦架西避军、为救法与妹开枪，法另想黑车可挡视弹并跑去开门。西解除自锁的结果仍有效，钥仍在锁孔；门只能从外锁，法选择留外关上，已中弹后给三指的机械师手势（`tz1:part0577:P0033–P0053`；TC10）。西知道法还情和失安妮，却明确不知拜伦为阿还是为尊严，不能替其补唯一爱情动机。新行动改变西对贵族的鄙视，不抹掉先前欺凌。

龙再强，有限能量和替包仍耗不过多批军械；前面杀敌真有效，后面受压也真。莱希特留矛抓腾空窗口，发现西不像逃者、走向架，便追枪毁架，敌人的观察也参与局面。璎珞以血救人后死，临别同脸同话重触西旧创，他想问身份仍未问明。不能从长得一样与超常血推完整复活来历（`tz1:part0578:P0002–P0036`）。

旧静梦此前只有等待不醒，这次首次问是不是来找自己，梦中对话称契约已达，具体何时何种契约仍不补。甲先吐龙遗体，后来活动的是空甲；西被吞后黑甲复起，能量终会耗尽，不是死者复活、也不等主角能永远驱动。截断巨傀降同高后凝视，把压迫落在尺度变化；最后教皇重机挡住猩红枪线、推倒已昏西，不是神力决斗分胜（`tz1:part0579:P0002–P0043`）。

## 方法与适用条件

保留物件状态与通道条件，让不同配角提出并承担自己的办法；救一人不证明总撤离成功。梦或重复景象的变化需有已给的基线，适合本来就有幻想机制的作品，不应移植成日常场面强制神秘化。接情节P2–P4、YM9及人物C1。
