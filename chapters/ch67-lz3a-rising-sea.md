# 67 潜龙升空之海：奇迹、补救与失败要分别保留其原因

## 方法与原因

**不同失败指向不同补救。** 幻觉不是缺勇气，距离不是缺信念，机械损伤不是再用一次强力就好。每次换办法，保留上一轮消耗和损坏，直到真正越过障碍；不强迫每种付出都换成功。

**奇迹按文本的力量来源分析。** 手机密码在此触发超自然命运，不是现实远程控制。可以选择这种写法，但需看到它如何压缩既有难题、谁仍执行剩余工作、是否新增交易代价；不虚构一套硬技术为其辩护。

**把失落与占有分开。** 路想被爱也怕孤独，仍主动拒绝剥夺诺诺意愿。后来羡慕楚心中虚拟夏弥完全属于他，是路当时的投射，不抹掉刚才明确拒绝囚禁的立场。

## 场景拆解与原创应用

出舱失知 → 楚赴险仍被困 → 路拒付更大代价与害人 → 获赠超自然密码 → 凯重动 → 带伤回舱 → 临时推进 → 回收失败 → 大范围审判 → 主角误认 → 留下一件可查实物。

原创示例：逃生通道靠异常力量打开，主角仍需辨方向、带上昏迷同伴；楼外救援车却已转移。下一场从剩余伤势与位置开始，不因奇迹把所有人重置为安全。若只想写朴素救援，就改用先前已建立的工具，别两种因果混写。

## 使用条件与失败方式

适合多层结尾与救援链。峰值力量不等于可精准救人，绘对路的好奇也反证源以为她绝不听任何外界的绝对判断。被抱和留鸭不证明已恋爱，路看到的女孩身份受视线、昏迷限制，须待后卷核对。台词、叙述、误认与实物分开，不提前借后续知识替本册收尾。
