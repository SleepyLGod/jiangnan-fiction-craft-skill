# 16 龙影：解决一个瓶颈，不等于完成救援

范围：《龙族Ⅰ》part0027–part0030；承接part0026末尾的地图。

## 文本观察

开图之后仍需传信、由钥匙画路、叶胜在城市重排前穿行。走出城与再浮到水面是两段时间，氧气并没有因得到地图而恢复。亚纪回想泳池里的往来，在当前困境中保护虚弱的叶胜；两人直接表白，并未削弱身体困境。锚点：lz1:part0026:P0061–P0067；lz1:part0027:P0002–P0049。

亚纪带出的罐子引来追逐。狙击、爆炸的第一判断被继续攻击修正，船闸、钥匙、铜罐与余下武器才构成后续办法。脱离危险仍有满船损失，曼斯临死请求隐瞒。校园先听到有限消息而欢呼，再以钟声、白巾进入悼念。停课、保险和换导师使死亡继续影响下一步生活。锚点：lz1:part0027:P0044–P0102；lz1:part0028:P0002–P0059、P0088–P0105；lz1:part0029:P0002–P0061。

路明非没有因此成为全知的救人英雄。他知道地图不来自自己的本事，旁人因名声招揽他，虚名变成选边的压力。宴会又先给尴尬结果，再倒回到场过程。锚点：lz1:part0029:P0062–P0081；lz1:part0030:P0002–P0075。

## 方法与原因

**把成功拆到实际任务链上。** 找路成功、通过机关、带回材料、人员生还、任务公开评价，不是同一个指标。逐项问谁完成、谁还被卡住，避免一次主角灵光便替全部人完成任务。

**让失败修正下一次办法。** 某种武器不能阻止追逐，下一次行动需要利用已知地形或敌人的目标。若只是换更大的爆炸，读者不易分辨战术变化，也难相信人物学到了什么。

**让损失进入组织的后续工作。** 换课、移交职责、安慰家属或办理保险不必全写，但挑一件真的改变下一人生活的事。这样伤亡不只是把悲伤音量拉高。

**分别记录行动结果与消息版本。** 学生欢呼并不证明行动无损；校长平静也不证明他没有失去人。读者、学生和领导知道的不同，就会有不同反应，不需要用旁白判某一方天生冷血。

## 场景拆解

地图解决方向 → 人必须按路线行动 → 氧气暴露遗漏 → 有人把生还机会交给搭档 → 带回物又使敌人继续追 → 船上以剩余条件脱身 → 消息被压缩传回 → 日常职责被重新分配。

原创改稿示例：远程技术员帮消防员打开一扇门。若楼内仍有烟和倒塌楼梯，就不能接一句“所有人都安全了”。让门后的队伍确认剩余人员、可走路线和谁无法移动，技术贡献才有准确分量。

## 使用条件与失败方式

适合团队任务、战争或灾难叙事。普通日常故事不必增加死亡以证明代价。也不要把每一次局部成功都紧接全盘失败，造成读者觉得人物努力永远无效。分清局部成果，才能让损失和贡献同时成立。

本卷的直接表白是有效场景，不能因偏好含蓄就删掉。是否直说取决于双方能否行动、是否还有时间，而不是固定文风禁令。

## 修改时看什么

成功到底解决了哪一项？剩余瓶颈有没有被忘记？谁知道伤亡、谁只知道任务结果？下一幕还受上一次损失影响吗？
