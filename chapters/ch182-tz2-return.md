# 182 炽天使的重临：具体写法与适用条件

## 文本观察

薇先说西可爱、未婚夫听她，西要求既是交易就说交易，才揭他是私生子、不具家族继承竞争资格这一利益条件。承诺是支持亚取得家主位，不等终身服从任何事（`tz2:part0649:P0044–P0053`）。拥抱既可庆祝交易又有温情，原文允许并存（`tz2:part0649:P0062–P0068`）。教授叹她变了，西以为是同感旧人的变化，后补她不给冰淇淋、变小气，把深沉的所指改回眼前小事。句子有效在说话者、听者理解和补句顺序，不只一个俏皮词（`tz2:part0650:P0003–P0011`；TY5）。

教授先讲古甲工艺，西看到欧米茄却想到灭口灾难（`tz2:part0650:P0028–P0035`）。人穿不上的结构，被教授解释为技术验证，西据亲见知道还有别种可能；专家也有现场不知道的资料（`tz2:part0650:P0043–P0047`）。经费不足的交易，经西的财政经验反问、薇指出挥霍、教授再解释竞争机关夺预算才展开（`tz2:part0650:P0056–P0076`）。实验十二分钟是纪录，却不等西已能独立驾甲；昆的欣喜被实验与战斗能力的区别修正（`tz2:part0652:P0030–P0034`；`tz2:part0652:P0045–P0047`）。

梦中他循光求休息，躲开十字架，以看不见火光为已逃掉；肩上黑发才揭自己一直背着它（`tz2:part0652:P0063–P0080`）。现实读数异常，新医疗组长未经历早年实验，误作崩溃，教授据记录改判狂化（`tz2:part0652:P0083–P0091`；`tz2:part0653:P0002–P0004`）。三骑合作想无伤制住，仍失败（`tz2:part0653:P0023–P0024`；`tz2:part0653:P0038–P0055`）。薇举光被旁人看作送死，西却抱着她叫妈妈；后揭她原想引开后接电缆，没料拥抱，只能连自己一起电击。计划成立、意外反应与临时承担须分开（`tz2:part0654:P0003–P0020`；TY6）。

醒后让床、挪靠椅、清洗创口耗时到少年睡着，最后薇把自己的毯子也盖给他，自己冷得蜷腿（`tz2:part0654:P0023–P0024`；`tz2:part0654:P0063–P0064`）。口气毒舌与具体照护并存，她拒说自己的噩梦，亲近仍有边界（`tz2:part0654:P0054–P0059`）。邻室教授问谁造的治疗机械，医生恭答是您，以事实回答形成笑，不需旁白另说他自作自受（`tz2:part0654:P0065–P0071`）。

## 编辑推断与可试操作

救场者可有原计划而不全知，把意外发生在哪个动作、付出如何变更写清。轻描淡写的话须对照身体与后续，不自动判全是假装。适合失控、实验与熟人照料等具体条件；梦境的空间、人格和神经机理均不作为现实心理结论。接观察、任务、笑点与帮助方法。
