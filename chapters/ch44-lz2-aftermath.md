# 44 每个人的心里都有个死小孩：余波以新的生活继续

范围：《龙族Ⅱ》part0143。

## 文本观察

赵与陈复合，赵对逃生的宗教叙述受学院心理暗示塑造，不是他完整知道真实经过。路祝福，也想到柳可能伤心；一段关系恢复不抹另一人的损失。他手机生命刻度剩二分之一，芬格尔又想念夏会带来的吃食，日常和代价并存。锚点：lz2:part0143:P0018–P0038。

楚去旧房，邻居却关心买房、误以为讨债。钥匙能开锁，他却觉得门重。过期酸奶、少量家具、落尘的整齐衣物、轻松熊枕头拼回夏的生活。他想象她独自学人类、向空房喊回来；文本保留“应该如此”，不能当亲见往事。每夜回忆的功课由此多出几件事。锚点：lz2:part0143:P0039–P0065。

KFC男解释帮助路像帮助灵魂里弱小的自己，是特定人物的看法。本卷未直接给其姓名。最后，学院暂拒婚约、家族利用审批施压，再揭诺诺原就是家族选中的新娘。真情与制度安排并存，不证明诺诺自己早知。锚点：lz2:part0143:P0066–P0088。

## 方法与原因

**让世界不为悲伤停下。** 邻居有孙子结婚的住房需求，失去者却面对不能再来的主人。同一扇门在双方那里是不同问题，日常谈价反使私人损失更具体；不必把邻居写成专门冷酷的人。

**让物证支持想象，又限定想象。** 柜中衣物和灰可见，过去每晚怎样过是楚重建。用一个试探句保留证据距离，能够有深情而不凭空全知。

**让结尾改写持续习惯。** 序幕每晚记住父亲，尾声再加上夏；死亡进入以后每天的工作。旧习惯可以增加内容、失去对象或改变做法，不只重复同一句象征。

## 场景拆解与原创应用

他人获新生活但认知被改写 → 主角祝福又想到第三人 → 契约数字留下成本 → 另一人走进遗屋 → 日常邻居插入不同需求 → 物件使过去可想象 → 记忆仪式改变 → 制度后台重释自由选择。

原创示例：合唱团散后，有人结婚、有人继续上课。旧排练室被问能否出租，指挥找到队友留下的杯子，不能由杯子知道对方所有心事，只把晚间名单多念一个名字。结尾若再揭场地早被机构预定，不应因此否认他们确实一起唱过。

## 使用条件与失败方式

适合大事件后的余波和系列收束。KFC男说“可能”有个死小孩，不是每位角色都必须同创伤、同命运。后续应用要保留当前角色目标，不能把用户角色换成通用衰小孩。没有样稿试验，不能声称这些方法已经提升作品质量。

修改时问：谁的日常在继续？哪些能证实，哪些仅想象？此后哪件习惯真的变了？与[ch10](ch10-cijian-departure.md)、[ch22](ch22-lz1-epilogue.md)对照。
