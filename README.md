# jiangnan-fiction-craft

从小说精读中提炼叙事方法，用于中文小说的构思、写作与修改。

当前版本 **0.1.0**，基于《此间的少年》十章及后记的全文阅读。关注场景因果、人物选择、对白、幽默、细节和时间结构，区分文本观察、编辑推断与原创应用建议。

## 使用

从 [SKILL.md](SKILL.md) 开始，根据当前问题加载相关章节。

> 使用 jiangnan-fiction-craft 评审这章小说。先找影响阅读最大的三个问题，再给局部修改稿；保留人物设定、既定视角和事实边界。
