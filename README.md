# jiangnan-fiction-craft

私人维护的中文小说构思与改稿 skill。当前版本 **0.1.0**，基于《此间的少年》本地文字版十章及后记的全文阅读，区分文本观察、编辑推断与原创应用建议。

它辅助场景因果、人物选择、对白、幽默、细节与时间结构的修改。它不是江南本人、官方项目或作者声线模型；不承诺复制作者文风。当前尚未纳入《龙族》《天之炽》，也尚未完成独立的改稿效果验证。

## 使用

从 [SKILL.md](SKILL.md) 开始。需要某个问题时按主题加载相关章节，不必一次读全部资料。

示例请求：

> 使用 jiangnan-fiction-craft 评审这章原创小说。先找影响阅读最大的三个问题，再给局部修改稿；保留人物设定、既定视角和事实边界，不添加新的原型经历。

- [sources/cijian-manifest.json](sources/cijian-manifest.json)：来源结构、文件指纹与段落锚点元数据，不含书籍正文。

## 维护方向

1. 用独立原创短场景检验改稿效果，记录成功和失败，避免只有原则没有作品。
2. 对照其他写作 skill 的构思、场景与修订流程，明确哪些改动有用；引用或采用他人内容时保留来源与适用许可。
3. 用户指定下一部作品后逐卷阅读，将证据和适用条件纳入同一个 skill，不用选读代表全书或全系列。

## 私人资料边界

仓库保持 **private**。仅保存指导、分析与必要来源元数据，不保存电子书、提取全文、逐段阅读语料、私人聊天、现实人物身份对应、凭据或私人链接。原始来源保持本地只读。

仓库的私有状态不等于拥有第三方作品的再许可权。本仓库不授予第三方文学作品或角色的任何权利。转为公开发布属于另一个明确决定，本次未授权。
